# BUTTMAN

The dark knight rises (literally, from squats). A two-page parody comic-book
landing for **BUTTMAN** — Gotham's most photogenic vigilante, billionaire by
day, leg-day all night.

## Pages

- `/` — hero with the bat-signal and BUTTMAN swooping in from the right
- `/memes.html` — origin timeline, comic-panel meme wall, glossary, FAQ

## Stack

- Vite (vanilla JS)
- One CSS file, one JS file, two HTML pages
- Character lives at `public/media/buttman.png`

## Run

```bash
npm install
npm run dev      # http://localhost:5177
npm run build
npm run preview
```
